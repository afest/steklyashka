# Стекляшка

Загрузите картинку и двигайте по ней стекло из ячеек-линз: каждая ячейка увеличивает кусок картинки вокруг своего центра, а то, что попало на шов, пропадает. Настраиваются форма ячеек, размер, увеличение и швы; результат сохраняется PNG в исходном разрешении.

Открыть: https://afest.github.io/steklyashka/

## Как это работает

Всё происходит в браузере: рендер — один фрагментный шейдер на WebGL2, сервера нет. В коде нет сетевых запросов с картинкой, она не покидает устройство. При работе сайт ничего не скачивает, кроме собственных файлов.

## Запуск

```
npm ci
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

Нужен Node 20.19+ и браузер с WebGL2.

## Что внутри

- `src/glass/` — модуль стекла: картинка и параметры на входе, отрисовка в canvas на выходе.
- `src/app/` — интерфейс на React.
- `src/lab/`, `lab.html` — лаборатория шейдера для разработки; открывается только в dev-режиме.
